# javis-installer

Bộ cài Javis cho máy **Windows**, dành cho người không rành máy tính.

## Cài bằng một dòng lệnh
Mở **PowerShell** (bấm Start, gõ PowerShell), dán dòng dưới đây rồi bấm Enter:

```
irm https://raw.githubusercontent.com/Mrxoppi/javis-installer/main/get-javis.ps1 | iex
```

## Hoặc tải gói về
Tải `javis-setup.zip` ở mục **Releases**, giải nén, bấm đúp `Cai-Javis.bat`.

Hướng dẫn chi tiết từng bước: [HUONG-DAN-CAI-DAT.md](HUONG-DAN-CAI-DAT.md).
